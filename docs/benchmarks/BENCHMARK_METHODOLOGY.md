# Benchmark Methodology & Reproducibility Protocol

## Benchmark Architecture

All performance metrics reported in this repository are generated by executing deterministic benchmark suites:
1. `python featurehub/benchmarks/run_benchmarks.py`
2. `python dataguard/benchmarks/run_benchmarks.py`

Output metrics are recorded directly into `featurehub/benchmarks/results.json` and `dataguard/benchmarks/results.json`.

---

## Measured Metrics

### FeatureHub Metrics
- **Redis Lookup Latency**: p50, p95, and p99 percentiles across 1,000 asynchronous key-value lookups.
- **Prediction Pipeline Latency**: End-to-end execution time combining Redis retrieval and scikit-learn model inference.
- **Cache Hit Rate**: Ratio of successful Redis key hits vs misses.

### DataGuard Metrics
- **Contract Parsing Duration**: Elapsed time parsing all 25 YAML contract definitions.
- **Schema Diff Latency**: Execution speed analyzing column additions, removals, type drift, and nullability edits.
- **Breaking Changes Blocked**: Ratio of breaking schema edits detected and flagged as `BREAKING`.
