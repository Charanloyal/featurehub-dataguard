# FeatureHub – Real-Time Feature Store Platform

FeatureHub manages feature definitions, point-in-time correct training dataset generation, offline Parquet storage, Redis online materialization, and real-time ML inference.

## Key Capabilities
- **120+ Real Features**: Windowed statistics across 6 feature groups.
- **Point-in-Time Joins**: Zero data leakage training dataset generation.
- **Redis Materialization**: Low-latency online feature retrieval for real-time prediction.
